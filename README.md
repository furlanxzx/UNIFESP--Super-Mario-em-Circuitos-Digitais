# 🍄 Super Mario em Circuitos Digitais

Projeto desenvolvido para a disciplina de **Circuitos Digitais**, ministrada pelo professor **Fábio Cappabianco**, na **UNIFESP (Universidade Federal de São Paulo)**, no 1º semestre de 2026.

O objetivo do projeto foi recriar o clássico jogo **Super Mario** utilizando exclusivamente circuitos digitais, simulados na ferramenta **Wired Panda**.

##  Ferramenta utilizada

- **Wired Panda** — versão `5.1.2`

> ⚠️ Para abrir o projeto corretamente, é recomendado utilizar a mesma versão do Wired Panda (5.1.2), evitando incompatibilidades com componentes ou funcionalidades de versões diferentes.

## 📦 Como baixar e abrir o projeto

O arquivo do projeto está compactado devido ao seu tamanho. Para utilizá-lo:

1. Baixe o arquivo `.zip` disponível neste repositório (clicando em projeto_enviado.zip -> "View raw").
2. Descompacte o arquivo em seu computador.
3. Abra o **Wired Panda** (versão 5.1.2).
4. Carregue o arquivo do projeto descompactado.

## 📚 Contexto

Este repositório documenta um projeto acadêmico da disciplina de Circuitos Digitais, com o desafio de implementar a lógica de um jogo inteiramente por meio de portas lógicas e componentes digitais, sem uso de programação tradicional.
